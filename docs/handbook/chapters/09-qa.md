# Q&A

Use these as short answers. Prefer saying *why*, then pointing at a concrete file.

## “Walk me through the architecture”

Hexagonal around `observations`: domain entities → `GetObservations` use case depending on Protocol ports → adapters for FastAPI, AEMET, SQLAlchemy. Shared cross-cutting: settings, Database, UnitOfWork, SingleFlight. Dependencies point inward.

## “Why ports as Protocol instead of ABC?”

Structural typing: fakes and real adapters only need matching methods. No forced inheritance hierarchy. Easy to inject in FastAPI `Depends` and in tests.

## “How does caching work?”

Cache **raw** 10-minute samples. Any rows in range = hit; empty = miss → fetch AEMET → upsert. Aggregate/project at **read time** so one cache answers many query shapes. Deliberate v1 shortcut: no gap-fill, no TTL.

## “What happens under concurrent cache misses?”

`SingleFlight` keyed by `(station_id, start_utc, end_utc)`: one fetch+upsert; other waiters await the same task. Plus SQLite WAL + `busy_timeout`. Limit: one process only; multiple workers can still stampede.

## “Why allowlist only two stations?”

Part 2 wanted a generic path, but only Antartida matches the historical + field shape. Other AEMET products differ (coverage and JSON). Dual-product experiment on `archive/aemet-dual-product` was out of take-home scope for `main`.

## “Why Unit of Work?”

Repository writes data; UoW owns **commit/rollback**. Keeps the repository a pure data-access adapter and makes transactional boundaries explicit in the use case (`async with self._uow`).

## “Timezone story?”

Three roles: `location` interprets naive query bounds; station timezone buckets aggregation; responses always `Europe/Madrid`. Antarctic stations bucket in UTC.

## “What would you do next in production?”

Auth / rate limits; Alembic; Postgres for multi-instance; Redis or DB locks for cross-process SingleFlight; gap-fill cache; readiness probe that checks DB; structured request-id logging.

## Sound bites (keep ready)

1. “Frameworks at the edges, business rules in the middle.”
2. “Cache once as raw samples; derive aggregates on read.”
3. “I document deliberate shortcuts (any-rows hit, no auth) so they aren’t mistaken for bugs.”
